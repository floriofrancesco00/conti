# Conti

App per segnare entrate e uscite dal telefono, a frase dettata («pizza 12 ieri»).
Funziona senza rete e i movimenti restano sul telefono di chi la usa (localStorage):
questo repository contiene solo il codice.

Si apre da https://floriofrancesco00.github.io/conti/ e si aggiunge alla schermata Home da Safari (Condividi → Aggiungi alla schermata Home).
